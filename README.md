# Hack The Box — Cybersecurity Learning Journey

Welcome to my Hack The Box learning repository.

This repository documents my hands-on journey through cybersecurity labs and modules on **Hack The Box**, with a focus on developing practical skills in networking, Linux, enumeration, web security, and security testing.

Rather than simply recording completed labs, I use this repository to document the **concepts I learn, tools I use, commands I practice, problems I encounter, and lessons I take away from each exercise**.

## 🎯 Learning Goals

* Build a strong foundation in cybersecurity and networking
* Strengthen Linux command-line skills
* Learn practical network and service enumeration
* Understand common protocols and network services
* Practice vulnerability identification and security testing
* Become comfortable with tools used in penetration testing
* Develop practical problem-solving and troubleshooting skills
* Build a documented cybersecurity portfolio
